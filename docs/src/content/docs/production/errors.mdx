Every failure returned by the SDK is a `*polipage.Error`. Use `errors.As` to extract typed fields and `errors.Is` against the package-level sentinels (`ErrUnauthorized`, `ErrDocumentGone`, …) for quick branching.

A sentinel matches by code, not by HTTP status. `ErrUnauthorized` matches `MISSING_API_KEY` and `INVALID_API_KEY`, and `ErrRateLimit` matches `QUOTA_EXCEEDED` and `OVERAGE_CAP_EXCEEDED`. To catch every `429`, use the `IsRateLimitError()` method; for a failed render, compare `Code` with `ErrCodeProjectNotFound`, `ErrCodeProjectNotInEnvironment` or `ErrCodeTemplateNotFound`.

## The error type

```go
var perr *polipage.Error
if errors.As(err, &perr) {
	fmt.Println(perr.Code, perr.StatusCode, perr.RequestID, perr.Message)
}
```

`*Error` implements `Unwrap`, so `errors.Unwrap(err)` gives you the underlying I/O / context cause when present.

## Example

```go
package main

import (
	"context"
	"errors"
	"fmt"
	"os"

	"github.com/poli-page/sdk-go"
	"github.com/poli-page/sdk-go/option"
)

func main() {
	client := polipage.NewClient(option.WithAPIKey(os.Getenv("POLI_PAGE_API_KEY")))

	_, err := client.Render.PDF(context.Background(), polipage.RenderInput{
		Project:  "billing",
		Template: "invoice",
		Data:     map[string]any{"invoiceNumber": "INV-001"},
	})
	if err != nil {
		var perr *polipage.Error
		if errors.As(err, &perr) {
			if perr.IsRateLimitError() {
				// RATE_LIMIT_EXCEEDED after the SDK's built-in retries, or
				// QUOTA_EXCEEDED / OVERAGE_CAP_EXCEEDED, which the SDK never
				// retries: queue the job for later, or report it as here.
				fmt.Fprintln(os.Stderr, "rate limited, try again later; request id:", perr.RequestID)
				os.Exit(1)
			}
			fmt.Println("code:", perr.Code, "request id:", perr.RequestID)
		}
		panic(err)
	}
}
```
